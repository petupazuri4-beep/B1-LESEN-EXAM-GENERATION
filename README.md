# B1 Lesen Exam Studio (Goethe- & ÖSD-Zertifikat B1)

Comprehensive examination suite for the **Goethe-Institut & ÖSD Zertifikat B1 (Modul LESEN)** with 10 authentic mock exams, interactive editor, digital CBT test simulation, optical answer sheet scanner, and high-fidelity PDF & DOCX export engine.

## Features
- **10 Complete Authentic Sets**: All 5 Teile, 30 items per set, 65 minutes, correct CEFR B1 vocabulary and authentic layout.
- **Offizieller Prüfungsbogen**: Print-ready A4 candidate paper with margin line numbering (every 5 lines) and draft note lines.
- **Antwortbogen S30**: Authentic candidate answer sheet with bubble grid and evaluator score matrix.
- **Digital CBT Simulation**: Realistic computer-based test mode matching the official Goethe-Institut digital exam software.
- **Optischer Antwortbogen-Scanner**: Instant bubble scanner, raw-to-scaled score conversion (0–100), and pass/fail diagnostics.
- **Lehrer-Dualansicht**: Split-screen with reading stimulus, German TTS audio pronunciation, text citations, and distractor rationale.
- **B1-Linter & Wortschatz-Prüfer**: Automated analysis of sentence lengths (8–15 words) and B1 vocabulary list check.
- **Export Engine**: Single-click export to DOCX, PDF, JSON, TXT, or full 10-set ZIP package.

## Quick Start
```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to access the application.
